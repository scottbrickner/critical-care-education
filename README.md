# Critical Care Education

Shared GitHub Pages repo for procedural and ICU learning modules, one folder per module.
Site: https://scottbrickner.github.io/critical-care-education/

| Module | Folder | Link |
|---|---|---|
| Floating the Swan · Norris 4 ICU (prep checklist + PA catheter refresher) | `swan-icu/` | https://scottbrickner.github.io/critical-care-education/swan-icu/ |
| Reading the Wave · waveform capnography for ICU RNs (Float Pool ICU Hub) | `capnography/` | https://scottbrickner.github.io/critical-care-education/capnography/ |
| Counting the Twitch · train-of-four & NMB for ICU RNs | `tof/` | https://scottbrickner.github.io/critical-care-education/tof/ |

`swan-icu/qr-swan-icu.png` is the QR code for that page; write the same URL to the NFC tag.
The PACU module still lives in the `pacu-education` repo and is linked from the hub page.

Add a module: new folder with its own `index.html`, add a row here and a link on the root `index.html`, commit, push.
